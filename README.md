# NumPy Study Notebook

A Turkish-language notebook for practicing NumPy. Each topic starts with an explanation and a worked example, followed by a similar exercise to solve. Solutions are included at the end.

[Open the notebook](NumPy_Detayli_Calisma.ipynb) · [NumPy Photo Editor project](https://github.com/yag1zkarag0z/numpy-photo-editor)

The notebook covers arrays, indexing, masks, broadcasting, aggregation, reshaping, and random sampling. To run it locally, install NumPy in a Python environment and select that environment as your Jupyter kernel.
